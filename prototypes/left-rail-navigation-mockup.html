Homebrewery — Left-Rail Navigation Mockup Idea 3: a persistent left rail added alongside the existing per-page toolbar

What's new

  • Left rail (48px): icon-only launcher, always visible, hover for tooltip. Provides global navigation.
  • Active-state indicator: orange bar on the left of the current-section icon, blue background fill.
  • Top toolbar: unchanged — each page keeps its existing save/export/share/etc. actions.
  • Rail items (from top): Logo → Home · New Brew · My Brews · Statblock Library · Willowlight · BESM · BRP · Palladium · (pinned brews) · (spacer) · Account · Help
  • Pinned brews: colored tiles with the brew's initials, placed below the feature links. Hover for the full title; click to jump straight into the editor.
  • Account & Help: live exclusively in the rail — removed from the top toolbars to cut duplication.

Design decisions

  • Account & Help: live in the rail only (removed from top toolbars).
  • Rail is always visible: no collapse behavior.
  • Pinned brews: colored tiles with initials, click-to-open, hover for full title.

Still to decide (when we build it)

  • How does a user pin a brew? (context menu on the brew card, star button in the editor, drag-and-drop?)
  • Cap on pinned count? (suggest 5–8 before it starts crowding the rail)
  • Should pinned character sheets / statblocks be pinnable too, or only brews?
  • Tile color: auto-assigned from brew ID, or user-pickable?
